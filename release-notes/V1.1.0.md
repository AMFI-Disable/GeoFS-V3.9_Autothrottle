# GeoFS-V3.9_Autothrottle Release Notes - V1.1.0

🛠️ Fixes & Improvements

- Replaced the compact draggable card UI with integrated autopilot controls injected directly into the native GeoFS Autopilot bar (`.geofs-autopilot-bar`).
- Added a native-style `LND` text label as a natural block element above the Landing Mode switch, accompanied by an explanatory hover tooltip (`Landing Mode (Auto-Retard on touchdown)`).
- Improved synchronization during autothrottle disengagement to automatically turn off OP Engines (thrust multipliers and ceiling bypass) if they were auto-engaged by OP-SYNC, returning the aircraft to standard physics safely.
- Added an absolute-positioned `[REV]` indicator that turns red and glows when reverse thrust is active.
- Enabled auto-selection of speed input text on focus/click for quicker target changes.
- Transitioned ecosystem authorship metadata (`@author` and `@copyright` headers) to reflect the new username `_init`.
- Updated copyright statements in userscript descriptions across all 52 supported languages to reference the new owner signature `© 2026 _init`.
- Synchronized all documentation, README footers, and release notes to standardize on the new username `_init`.
- Enforced strict case-sensitive name formatting by replacing all spaced or lowercase variations (e.g. `GeoFS-V3.9` or `GeoFS-V3.9`) with the exact `GeoFS-V3.9` branding.
- Removed the credits sections containing references to `NightKeys` and `LunarBlink` from the profile README and all 11 standalone README files to consolidate authorship.
- Cleaned up the Design System documentation by removing old Codeberg repository links and replacing them with plain text module references.
